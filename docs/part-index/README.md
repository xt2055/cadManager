# 零件视图一期：实施入口

编写日期：2026-09-09。

本目录包含零件视图一期的实施契约、执行进度和验证记录。实现状态以 [progress.md](./progress.md) 为准。

## 日常使用：读取图纸生成索引

零件索引是从零件图标题栏生成的检索数据，不是 BOM 数量清单，也不会修改原始 CAD 文件。

- **全选本页 / 读取所选图纸**：选择有写权限的文件，重新读取 CAD 标题栏并更新索引。已识别文件也能重新读取，保留已经保存的人工修订；识别完整后直接可用，不要求人工确认。
- **生成待完善索引**：按当前筛选条件跨页收集有权限的待提取、失败文件，确认数量后串行处理。缺少标题栏或此前失败时读取 CAD；已有有效快照但缺索引时直接同步。没有筛选条件时处理全部符合条件的零件图。
- **进度和重试**：显示固定总数、当前文件及失败原因；支持停止、重试失败项。收集失败不会启动部分队列。任务在当前页面运行，离开页面后不再启动下一文件，正在处理的文件可能仍会完成。
- **查看详情**：识别完整的图号和零件名称会直接用于检索，无需逐条确认；只有关键信息缺失、多个布局无法自动确定、读取失败或历史确认数据遇到换版时才提示检查。发现识别错误时可保存人工修订，重新读取会保留这些修订。
- **高级维护 → 修复已有索引（不读取图纸）**：管理员全局快照同步工具，与当前筛选条件无关。它不能读取尚未识别的 CAD，不应当作日常生成入口。

读取复用 `extractAndSaveTitleBlock()` 与 `/cad/source` 的前端 CAD 解析链路，不使用仅按文件名识别图号的旧接口。后端权限和当前附件版本校验保持不变。

上述入口更新取代实施基线中“仅待提取/失败条目可勾选”和将快照补建作为常用按钮的交互约定；接口和数据模型不变。

## 本次最重要的约束

- 一个零件索引公开地址对应一个附件，数据库记录按附件版本区分。
- 同一附件可以关联多个项目，不能复制索引来表达借用关系。
- 项目显示编号使用现有 `drawings.project`；内部关联及筛选使用 `drawings.id`。
- 标题栏图号、总图图号、项目编号是三个不同字段。
- 人工修正保存在索引层，不改 CAD 文件、不改正式零件版本数据。
- 所有当前查询必须匹配 `attachments.current_version_id`。
- 缺少当前版本识别结果时显示待提取，不能拿旧版本字段顶替。
- 当前系统代码的读取策略是登录后共享读取；本文一期继承该策略，**不宣称已经实现按项目成员隔离**。具体边界见主文档第 5 节。
