```text
Vue → domain.store → dataManager → /api/data/* → 整表写入
```

```text

        ↓
Application Command / Query
        ↓
Domain
        ↓
Repository / Gateway
        ↓
Atomic API
        ↓
Go Transaction + Revision
```

## 已冻结的关键规则

- Part 是全局唯一的稳定工程零件身份。
- PartRevision 是零件工程内容版本。
- Borrowed Part 动态读取源 Part 最新 PublishedRevision。
- V1 不支持借用完整装配子树。
- Borrowed Part 不允许直接修改，修改必须 Fork。
- Draft 可编辑并使用 `row_revision` CAS。
- Reviewing 禁止普通编辑，只能通过审核动作。
- Published 永久不可修改。
- DrawingPartRelation 是图纸中的使用实例，关系自身带 `revision`。
- `qty`、`parent`、`position`、`remark` 属于 Relation。
- 结构禁止成环，同一 Drawing 的结构写入使用 drawing-level lock。
- Fork 采用旧 borrowed relation 归档、新建 owned relation，并保留 lineage。
- 附件按 Attachment、AttachmentVersion、Blob 分层；`part_revision_attachments` 只引用 `attachment_version_id`。
- 旧 Tauri 客户端本次不兼容，前后端必须一起升级。
