# CAD Demo UI 一比一迁移

## 目标

将 `test/代码_2026-08-21T11-02-24-762335.html` 的默认界面、四套主题、页面结构、虚拟数据和主要交互迁移到 `vue/cad`，不再使用空页面占位。

## 已确认基准

- 原始 HTML 使用 `Noto Sans SC`、`Noto Serif SC`、`JetBrains Mono`，默认主题为 `tech + dark`。
- 外层窗口需要 `body` 14px 内边距、圆角应用壳、48px 自绘标题栏、216px 侧栏、27px 状态栏。
- 默认页面为工作台，包含统计卡片、最近动态、待审核、转换服务、文件存储、进行中项目。
- 主导航包含主导航、追溯、管理三个分组；图纸详情包含 8 个子页。
- 原始 Demo 包含图纸库、详情、CAD SVG 预览、结构、版本、借用、备料、工艺、审核、属性、审核中心、日志和后台管理。
- 图标通过 Lucide CDN 加载；Vue 迁移使用本地 `lucide-vue-next`，避免外部 CDN 请求。
