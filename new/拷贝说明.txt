cadguanliq 部署包（2026-08-31，纯 Python 脚本版）
==================================================
安装/维护脚本统一使用 Python，配合包内便携运行时运行，不再有 bat/ps1。

【服务器（C:\Users\Administrator\Desktop\pack）】
0. cad-data\            → 整个文件夹拷到 Desktop\pack\cad-data\（CAD 字体库，客户端渲染文字时从服务器下载）
1. install.py           → 覆盖到 Desktop\pack\（SMB 自动开启 + 字体接口）
2. cadguanliq.exe       → 覆盖到 Desktop\pack\（新增 /cad-data/fonts/ 字体下载接口 + 转换超时加大 + CAXA 自动探测）
3. tools\exb2dxf\exb2dwg.crx
                        → 覆盖到 Desktop\pack\tools\exb2dxf\
                        → 并再拷一份到 C:\Program Files\CAXA\CAXA CAD\2022\Bin64\（覆盖，插件会自动关闭 CAXA 恢复弹窗）

执行安装（命令行，先结束正在运行的 cadguanliq.exe）：
    cd C:\Users\Administrator\Desktop\pack
    runtime\python\python.exe install.py

【客户端】
4. 图枢_0.1.0_x64-setup.exe → 双击安装（内嵌 WebView2 完整运行时，无 WebView2 的机器直接装即可）。
   客户端字体地址指向服务器 http://<服务器IP>:8080/cad-data/fonts/，
   务必确认服务器上已部署 cad-data 文件夹且服务已重启。

【维护工具（在 Desktop\pack 里执行）】
- 添加/重置管理员：
    runtime\python\python.exe add-admin.py [账号] [密码] [显示名]
- 补图纸缺失字体（装到 CAXA + 前端字体库）：
    runtime\python\python.exe add-fonts.py <字体所在目录>

【验证】
- 服务器日志出现 "[SMB] 成功：共享已创建/已存在 \\IP\CadWorking" 即 SMB 正常
- 浏览器访问 http://<服务器IP>:8080/cad-data/fonts/fonts.json 应返回 JSON（不是 HTML）
- 客户端打开图纸预览，标注文字正常显示
- dwg 上传识别不再报 "CAXA 转换任务超时/任务队列等待超时"
